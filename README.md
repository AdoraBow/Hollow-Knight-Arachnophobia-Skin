# Hollow-Knight-Arachnophobia-Skin
A Custom Knight skin that removes the legs of some enemies that triggered my arachnophobia.

## What is changed?
The legs of the following enemies have been removed:
- Corpse Creeper
- Deephunter
- Deepling
- Lesser Mawlek
- Little Weaver
- Loodle
- Nosk / Nosk Statue (Godhome)

The legs of the Weaversong charm have also been removed.

## How to install?
1. Install [Custom Knight](https://github.com/PrashantMohta/HollowKnight.CustomKnight)
2. Download the skin from the [releases](https://github.com/AdoraBow/Hollow-Knight-Arachnophobia-Skin/releases/tag/1.0).
3. Unpack the zip under ./Hollow Knight/hollow_knight_Data/Managed/Mods/Custom Knight/Skins/
4. Select the skin in the Custom Knight menu opened by pressing DEL in the pause screen.

## I already use a different Custom Knight skin. How can i use another one?
Unfortunately Custom Knight doesn't allow multiple skins to be selected at the same time. To circumvent this you can merge the skin folders.
### Important
When merging skin folders make sure to manually merge the names.json file under ./Arachnophobia/Swap/GG_Workshop/ otherwise the Nosk Statue replacement will not work.
